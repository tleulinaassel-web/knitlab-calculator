KNITLAB SCHOOL

Калькулятор реглана

Пошаговые расчёты изделия снизу вверх с V-образной горловиной для однофонтурной машины.

Этап 1 из 5

Плотность и параметры изделия

Внесите плотность образца и размеры. Для плотности укажите количество петель/рядов и соответствующий размер образца.

Заполните размеры, чтобы увидеть расчёт.

Набор петель округляется вверх до ближайшего чётного числа. Высота до подрезов: дробную часть убираем; если целая часть нечётная, прибавляем 1, если чётная — оставляем. Подрезы не округляются: размер каждого подреза переводится в петли по плотности как есть; калькулятор показывает расчёт для одного подреза и суммарно для двух.

Этап 2 из 5

Фактический реглан спинки

Заполните после того, как свяжете реглан спинки. Вводятся реальные значения с машины.

Введите фактические данные спинки.
Этап 3 из 5

Реглан переда и V-образная горловина

Перед рассчитывается по введённым данным спинки. Убавки горловины показаны отдельно от убавок реглана.

Сначала заполните данные спинки.

Расчёт V-образной горловины

Этот расчёт отдельный: убавки V-выреза не входят в убавки реглана переда.

После ввода данных спинки здесь автоматически появятся петли на каждой стороне, резерв для шва, количество шагов и интервал убавок V-выреза.

Количество петель на стороне переда рассчитывается автоматически: остаток переда делится пополам. Для нечётного количества на стороне оставляем 3 петли для шва, для чётного — 4. Остаток на убавки делится на 2, поскольку за один шаг убавляются 2 петли. Интервал показывается как высота реглана переда, делённая на число шагов.

Этап 4 из 5

Рукав: широкая часть и шаг прибавок

Сначала рассчитаем самую широкую часть рукава, затем количество прибавок и средний интервал между ними. Только после этого перейдём к номеру ряда начала ростка.

Введите параметры рукава и проверьте расчёт широкой части и интервалов прибавок.

Формула широкой части по вашей методике: подрезы с двух сторон + половина убавок спинки + половина убавок переда (без V-выреза) + половина остатка спинки. Если расчёт прибавок на сторону даёт дробное число, дробная часть отбрасывается; интервал считается по целому числу прибавок.

Этап 5 из 5

Начало формирования ростка

Калькулятор показывает только номер ряда — без инструкций по вязанию.

Сначала рассчитайте высоту реглана переда.
Подрезы не округляются. Набор петель изделия округляется вверх до ближайшего чётного числа. Дробная часть числа прибавок рукава отбрасывается; интервал считается по целому числу прибавок.
